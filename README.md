# 🛒 Amazon Clone (E-Commerce Platform)

This is a simple Amazon Clone UI built using HTML and CSS.  
The project replicates the basic layout and design of an e-commerce website like Amazon.

---

## 🚀 Features

- Homepage layout
- Navigation bar with logo and search bar (UI only)
- Product sections
- Banner section
- Responsive design
- Clean UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3

---

## 📂 Project Structure

```
amazon-clone/
│
├── index.html
├── style.css
└── images/
```

---

## ▶️ How to Run

1. Download or clone the repository  
2. Open the project folder  
3. Open `index.html` in your browser
